# عُدّة — الحزمة الشاملة

صفحة بيع واحدة لمنتج رقمي واحد بسعر **499 ر.س**. عملية الشراء تستخدم **Moyasar Hosted Invoices** ثم تتحقق من حالة الفاتورة على السيرفر قبل إظهار رابط التحميل.

## التشغيل

```bash
npm install
npm run dev
```

الواجهة تعمل عبر Vite. مسارات `/api` مصممة كـ Vercel Functions، لذلك لاختبار الدفع محليًا استخدم بيئة تدعم هذه الوظائف مثل `vercel dev`.

## متغيرات البيئة المطلوبة

- `MOYASAR_SECRET_KEY`: المفتاح السري من Moyasar، واستخدم مفتاح الاختبار أولًا.
- `SITE_URL`: رابط الموقع النهائي، مثال: `https://uddah.example.com`.
- `UDDAH_DOWNLOAD_URL`: رابط تحميل الحزمة الذي يُعاد فقط بعد التحقق من نجاح الدفع.

لا تضع مفتاح Moyasar السري داخل ملفات الواجهة أو متغيرات Vite العامة.

## تدفق الشراء

1. المستخدم يضغط شراء.
2. `POST /api/create-checkout` ينشئ فاتورة بقيمة 49900 هللة.
3. المستخدم ينتقل إلى صفحة الدفع المستضافة من Moyasar.
4. بعد نجاح الدفع يعود إلى `/?checkout=complete`.
5. `GET /api/verify-payment?id=...` يجلب الفاتورة من Moyasar ويتحقق من:
   - `status === "paid"`
   - `amount === 49900`
   - `currency === "SAR"`
6. عند نجاح التحقق فقط يظهر `UDDAH_DOWNLOAD_URL`.

## قبل الإطلاق

استخدم مفاتيح الاختبار وأكمل دورة دفع كاملة، ثم بدّل إلى مفاتيح الإنتاج بعد تفعيل حساب Moyasar وضبط رابط التحميل.
